## 주요 변경사항
**1. 인증 / 인가 기능 구현**
(1) 회원가입
이메일, 닉네임, 비밀번호를 입력 받아 사용자를 등록합니다.
비밀번호는 bcrypt를 이용해 해싱 후 저장합니다.

(2) 로그인
passport-local 전략을 활용하여 사용자 인증을 구현 했습니다.
로그인 성공 시 Access Token 및 Refresh Token 을 발급합니다.
발급된 토큰은 HttpOnly로 쿠키에 저장됩니다.

**2. 토큰 기반 인증 / 인가**
(1) JWT 유틸 함수 구현
generateTokens, verifyAccessToken, verifyRefreshToken 함수를 정의했습니다.
각각 액세스/리프레시 토큰 생성 및 유효성 검증을 수행 합니다.
리프레시 토큰은 DB에 저장하여 보안성을 강화했습니다.

(2) Passport JWT 전략 적용
Access Token / Refresh Token 각각의 전략을 정의했습니다.
토큰 유효성 검증 후 req.user에 사용자 정보를 바인딩 했습니다.

**3. DB 스키마 변경 사항**
User 모델에 refreshToken 필드를 추가 했습니다.
Refresh Token 기반의 인증 흐름을 위해 사용자의 토큰 정보를 DB에 저장하도록 수정했습니다.
